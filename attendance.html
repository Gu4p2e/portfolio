勤怠管理システム

概要

社員の出退勤を記録・管理するためのWebアプリケーションです。日々の勤怠データをデータベースに保存し、管理者は出勤状況を一覧で確認できます。

開発背景・目的

勤怠管理は多くの企業で必須の業務であり、実務に直結する開発経験を積むことを目的に制作しました。ログイン・登録・一覧表示・編集・削除といった基本的な機能を実装しています。

使用技術

  • Java
  • Spring Boot
  • PostgreSQL
  • Git / GitHub

工夫したポイント

・エラーハンドリングを丁寧に行い、入力ミスやDB接続エラーに対応できるようにしました。
・シンプルなUI設計にこだわり、初めて使う人でも直感的に操作できるよう工夫しました。
